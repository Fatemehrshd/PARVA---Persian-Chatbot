# راهنمای قابلیت‌های پنل ادمین (Admin Panel)

این سند راهنمای کامل و ساده‌ای برای استفاده، تست و آشنایی با امکانات پنل مدیریت (Admin Panel) در بکند پلتفرم است. تمامی این قابلیت‌ها طبق استانداردهای NestJS پیاده‌سازی شده و از طریق اندپوینت‌های ایمن در دسترس ادمین سیستم قرار دارند.

---

## ۱. امنیت و سطح دسترسی (Authentication & Authorization)
- کلیه مسیرهای پنل ادمین با پیشوند `/admin/` شروع می‌شوند.
- دسترسی به این اندپوینت‌ها مستلزم ارائه **Bearer Token معتبر** و داشتن نقش ادمین (`role: 'admin'`) است:
  - اگر کاربری لاگین نکرده باشد: خطای `401 Unauthorized` دریافت می‌کند.
  - اگر کاربری لاگین کرده باشد اما نقشش ادمین نباشد: خطای `403 Forbidden` دریافت می‌کند.

---

## ۲. تنظیم سقف مصرف توکن گلوبال (Global Token Limit)
### هدف:
مدیریت هزینه‌ها و منابع با مشخص کردن یک سقف کلی برای میزان مصرف توکن توسط هر کاربر.

### نحوه عملکرد:
- ادمین می‌تواند یک عدد برای سقف توکن تعیین کند (مثلاً ۵۰,۰۰۰ توکن).
- این سقف به صورت **گلوبال** تعریف می‌شود؛ یعنی یک حد نصاب یکسان برای همهٔ کاربران است.
- اگر این مقدار روی `0` تنظیم شود، محدودیت برداشته شده و نامحدود خواهد بود.
- هر بار که کاربر پیامی ارسال می‌کند و مدل به آن پاسخ می‌دهد، میزان توکن مصرفی بر اساس حجم پیام و پاسخ محاسبه شده (`Math.ceil((ورودی + خروجی) / 4)`) و به مقدار `usedTokens` آن کاربر اضافه می‌شود.
- در صورتی که کاربری به این سقف رسیده باشد، هنگام تلاش برای ارسال پیام جدید فوراً خطای مشخصی دریافت می‌کند:
  > **پیام ارور سیستم:** `سقف مجاز مصرف توکن به پایان رسیده است` (کد ۴۰۰)

### اندپوینت‌ها:
- دریافت تنظیمات فعلی: `GET /api/v1/admin/settings`
- ویرایش سقف توکن: `PUT /api/v1/admin/settings` با بدنهٔ JSON:
  ```json
  {
    "globalTokenLimit": 50000
  }
  ```

## ۳. تغییر متن پرامپت سیستم (Dynamic System Prompt)
### هدف:
تعیین لحن، شخصیت و نحوهٔ معرفی دستیار هوش مصنوعی برای تمامی چت‌های کاربران.

### نحوه عملکرد:
- به صورت پیش‌فرض، پرامپت اولیه سیستم عبارت است از:
  `You are a helpful and knowledgeable AI assistant.`
- ادمین می‌تواند هر زمان این متن را تغییر دهد؛ مثلاً:
  > *«تو یک دستیار هوشمند و حرفه‌ای به نام پروا هستی و همیشه به زبان فارسی محترمانه و دقیق پاسخ می‌دهی.»*
- بلافاصله پس از ذخیره، تمامی پیام‌ها و چت‌های جدید کاربران با این پرامپت به پرووایدر ارسال می‌شوند.

### اندپوینت‌ها:
- ویرایش پرامپت سیستم: `PUT /api/v1/admin/settings` با بدنهٔ:
  ```json
  {
    "systemPrompt": "تو یک دستیار هوشمند و حرفه‌ای به نام پروا هستی."
  }
  ```

## ۴. لیست کاربران و آمار مصرف (User Management & Analytics)
### هدف:
امکان مشاهدهٔ تمام اعضای ثبت‌نام شده، به همراه وضعیت مصرف منابع و تعداد چت‌های آن‌ها.

### اطلاعات نمایش‌داده‌شده برای هر کاربر:
1. **شناسه (`id`)** و **ایمیل (`email`)**
2. **نام نمایشی (`displayName`)** و **نام کاربری (`username`)**
3. **نقش کاربر (`role`)**: `user` یا `admin`
4. **آدرس آواتار (`avatarUrl`)**
5. **تعداد چت‌های ساخته‌شده (`conversationsCount`)**: تعداد مکالمات ایجاد شده توسط این کاربر.
6. **میزان توکن مصرفی (`usedTokens`)**: مجموع توکن‌های مصرف‌شده توسط کاربر تاکنون.
7. **تاریخ عضویت (`createdAt`)**

### امکانات ویرایش و حذف کاربر توسط ادمین:
- **ویرایش کاربر:** ادمین می‌تواند نقش کاربر را تغییر دهد (ارتقا به ادمین یا تبدیل به کاربر عادی)، نام و ایمیل او را اصلاح کند، یا توکن‌های مصرف‌شده او را ریست کند (مثلاً `usedTokens: 0` برای تمدید اعتبار).
- **حذف کاربر:** ادمین می‌تواند حساب کاربر را به همراه تمامی چت‌ها و پیام‌های متصل به آن به صورت آبشاری حذف کند.
  - *محافظت سیستمی:* ادمین نمی‌تواند حساب کاربری خودش را حذف کند (`Cannot delete self`).

### اندپوینت‌ها:
- دریافت لیست کاربران و آمار: `GET /api/v1/admin/users`
- ویرایش کاربر: `PATCH /api/v1/admin/users/{userId}`
  ```json
  {
    "role": "admin",
    "usedTokens": 0
  }
  ```
- حذف کاربر: `DELETE /api/v1/admin/users/{userId}`

---

## ۵. مدیریت پرووایدرها (AI Providers)
پرووایدرها ارائه‌دهندگان سرویس مدل هستند (مانند OpenAI، Ollama، OpenRouter و غیره).

- **ثبت پرووایدر:** `POST /api/v1/admin/providers` (تعیین نام، Base URL و کلید API).
- **لیست پرووایدرها:** `GET /api/v1/admin/providers` (کلیدهای API به صورت ماسک‌شده `sk-...1234` بازگردانده می‌شوند).
- **ویرایش پرووایدر:** `PATCH /api/v1/admin/providers/{providerId}` (تغییر نام، آدرس یا تعویض کلید).
- **فعال/غیرفعال کردن:** `PATCH /api/v1/admin/providers/{providerId}/status` (با خاموش شدن پرووایدر، مدل‌های آن هم در چت موقتاً از دسترس خارج می‌شوند).
- **تعیین مدل پیش‌فرض پرووایدر:** `PATCH /api/v1/admin/providers/{providerId}/default`.
- **حذف پرووایدر:** `DELETE /api/v1/admin/providers/{providerId}` (به همراه حذف آبشاری مدل‌های مربوطه).

---

## ۶. ساخت، ویرایش و اتصال مدل به پرووایدر (AI Models)
- **ساخت مدل جدید:** `POST /api/v1/admin/models` با اتصال مستقیم به پرووایدر:
  ```json
  {
    "name": "GPT-4o",
    "providerId": "uuid-of-provider",
    "apiIdentifier": "gpt-4o",
    "isActive": true
  }
  ```
- **ویرایش مشخصات مدل:** `PATCH /api/v1/admin/models/{modelId}`:
  امکان تغییر نام مدل، تغییر پرووایدر متصل، شناسه مدل در API، آدرس پایه و فعال/غیرفعال بودن.
- **تغییر وضعیت فعال/غیرفعال:** `PATCH /api/v1/admin/models/{modelId}/status`.
- **انتخاب به عنوان مدل پیش‌فرض پلتفرم:** `PATCH /api/v1/admin/models/{modelId}/default`.
- **حذف مدل:** `DELETE /api/v1/admin/models/{modelId}`.

---

## ۷. داشبورد و شاخص‌های آماری پلتفرم (Admin Dashboard Stats)
### هدف:
ارائه نمایی جامع و لحظه‌ای از کلیه داده‌های مهم سامانه جهت تصمیم‌گیری و پایش.

### شاخص‌های آماری:
- `totalUsers`: تعداد کل کاربران ثبت‌نام‌شده
- `totalModels`: تعداد کل مدل‌های تعریف‌شده
- `activeModels`: تعداد مدل‌های فعال و آماده برای چت
- `totalProviders`: تعداد کل پرووایدرها
- `activeProviders`: تعداد پرووایدرهای فعال
- `totalConversations`: تعداد کل جلسات گفتگو (Sessions / Chats)
- `totalMessages`: تعداد کل پیام‌های ردوبدل شده
- `totalTokensUsed`: مجموع کل توکن‌های مصرف‌شده در کل پلتفرم
- `globalTokenLimit`: سقف توکن گلوبال در حال حاضر
- `systemPrompt`: متن پرامپت فعال سیستم

### اندپوینت:
- `GET /api/v1/admin/dashboard/stats`

## ۸. جدول خلاصه اندپوینت‌های API ادمین

| متد | مسیر (Path) | توضیح عملکرد |
| :--- | :--- | :--- |
| **GET** | `/admin/dashboard/stats` | دریافت آمار جامع و شاخص‌های کلیدی داشبورد |
| **GET** | `/admin/settings` | مشاهده سقف توکن و پرامپت فعال سیستم |
| **PUT** | `/admin/settings` | تغییر سقف توکن گلوبال یا پرامپت سیستم |
| **GET** | `/admin/users` | لیست کاربران همراه با تعداد چت‌ها و توکن مصرفی |
| **PATCH** | `/admin/users/{userId}` | ویرایش نقش، اطلاعات یا ریست توکن کاربر |
| **DELETE** | `/admin/users/{userId}` | حذف کامل یک کاربر و چت‌های او |
| **GET** | `/admin/models` | لیست تمامی مدل‌ها |
| **POST** | `/admin/models` | تعریف مدل جدید و اتصال به پرووایدر |
| **PATCH** | `/admin/models/{modelId}` | ویرایش فیلدهای مدل (نام، پرووایدر، شناسه و...) |
| **PATCH** | `/admin/models/{modelId}/status` | فعال/غیرفعال‌سازی مدل |
| **PATCH** | `/admin/models/{modelId}/default` | تنظیم مدل به عنوان پیش‌فرض پلتفرم |
| **DELETE** | `/admin/models/{modelId}` | حذف مدل |
| **GET** | `/admin/providers` | لیست تمامی پرووایدرها |
| **POST** | `/admin/providers` | تعریف پرووایدر جدید |
| **PATCH** | `/admin/providers/{providerId}` | ویرایش پرووایدر |
| **PATCH** | `/admin/providers/{providerId}/status` | فعال/غیرفعال‌سازی پرووایدر |
| **PATCH** | `/admin/providers/{providerId}/default` | تعیین مدل پیش‌فرض پرووایدر |
| **DELETE** | `/admin/providers/{providerId}` | حذف پرووایدر و حذف آبشاری مدل‌های آن |
